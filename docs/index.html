About this demo

This static page performs inference with ONNX Runtime Web using the yolov11-seg-brain.onnx model published on Hugging Face. The image is letterboxed to 256×256, passed through the network, then boxes and instance masks are rendered on the canvas.

Model repository: shahriarhd/brain-scan-ai-yolov11-seg · Project: GitHub
